## The joke

> My horoscope said to take a risk today, so I opened my banking app.

## How it works

`main.py` writes that single one-line comedy joke to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints it. No network, no secrets,
no dependencies — just the joke.

## Run it

```sh
python3 main.py
```
